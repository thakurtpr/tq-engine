## Reading guide and repair PROPOSALS (nothing below has been applied; declare in the protocol's dated addendum)

Codes R* are row defects; codes E* are SEMANTIC properties of the exchange files (not errors, but a backtest that ignores them
is wrong); codes I* concern the index/VIX files.

| Defect | Interpretation | Proposal (not applied) |
|---|---|---|
| E01 / E02 expiry-day `settle` | settle is 0 (to 2020-01-30) or the underlying settlement price (from 2020-02-06), never an option premium | never mark or fill on `settle` on the expiry day; compute expiry payoff from the underlying settlement; use `close` of the last traded session only when volume > 0 |
| E03 expiry label on a holiday | contract really expires on the previous trading day | map expiry label to last trading day via tq-calendar before any DTE calculation |
| R04 settle <= 0 on traded rows (non-expiry) | exchange published no settlement for a traded row | use `close` with volume > 0 as the mark; exclude from any settle-based valuation |
| R06 / R21 close outside [low, high] / OHL all zero on traded rows | isolated vendor-style print defects (hundreds of rows over 15 years) | drop the row from fills and marks (treat as not tradeable that session); do not interpolate |
| R10 / R12 / R13 strikes or prices inconsistent with the underlying | corporate-action contracts (BAJFINANCE 2016-09 split, ASHOKLEY 2014-05, YESBANK 2019-2020 near-zero prices, RELIANCE 2023-07-19) | exclude the affected symbol-dates (listed in options-v2-dq-defects.csv) from stock-option universes; flag in the addendum |
| R19 mixed lots in one session | contracts listed before and after a lot revision | key lot by contract (the `lot_size` column), never by date |
| R20 non-integer volume (LT 2013-07-10) | source defect | drop those 4 rows |
| I01c index_date != file_date (3 files, 2023-04) | month/day swapped inside the file | key on `file_date` (the compact keeps both) |
| missing sessions (2013-10-09, 2021-03-30 F&O; index-file holes) | source gaps | do not forward-fill option data across a gap; skip the session; mark signal dates on gap days as untradeable |
| row-count collapses (FINNIFTY 2024-11) | weeklies withdrawn, not a defect | none |
